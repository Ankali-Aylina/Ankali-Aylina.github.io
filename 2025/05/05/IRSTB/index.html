智能散热小桌板

智能散热小桌板

项目简介

智能散热小桌板是一个软硬件结合的桌面散热系统：硬件端以 CW32L010 为主控，通过蓝牙接收电脑温度并驱动风扇；上位机软件（TCV3）实时监测电脑 CPU / GPU 温度，根据温度自动调节风扇转速，为你带来清凉舒适的使用体验。

简单来说：电脑热了，小桌板自己就把风扇开大了。

下载与安装

  • GitHub Releases：https://github.com/Ankali-Aylina/IRSTB/releases
  • 下载 TemperatureControlV3_vX.X.X.X_Setup.exe 安装包，一路下一步即可
  • 首次启动会自动提示安装所需驱动（Intel 需 PawnIO 驱动，AMD 需 AMDRyzenMaster 驱动）
  • 支持项目请前往 支持与文档

功能特点

硬件端（桌板）

  • 主控芯片：CW32L010（ARM Cortex-M0+，低功耗高性能）
  • 蓝牙无线通信：DX-BT24-T 模块（BLE 4.2），与上位机无线连接，免布线
  • 风扇自动调速：12V 直流风扇，PWM 调速，安静又清凉
  • 状态感知：实时监测桌面温湿度与风扇运行状态

上位机 TCV3（软件）

  • 全平台温度监测：Intel CPU（PawnIO/MSR 直读）、AMD CPU（RyzenMaster 驱动）、NVIDIA GPU，开机即测
  • 智能调速算法：多级温度策略 + 滑动窗口加权平均 + 滞后防抖（温度下降需连续确认，避免风扇频繁跳变）
  • 三种风扇模式：自动（温度驱动）/ 静音 / 全速，一键切换
  • 现代化 WinUI 风格界面：基于 Qt Quick (QML) 重写，圆角卡片、流畅动画
  • Windows 11 背景材质：云母 (Mica) / 亚克力 (Acrylic) 原生质感
  • 浅色 / 深色双主题：跟随系统自动切换，或手动指定；图标随主题自动着色
  • 便捷使用：开机自启、最小化到系统托盘、蓝牙断线重连、更新日志内嵌

使用教程

1. 安装与驱动

  1. 下载 安装包 并安装（需 VC++ 运行库）
  2. 首次启动会检测硬件驱动，按提示安装即可：
    • Intel CPU：需安装 PawnIO 驱动（程序内置安装器，自动静默安装）
    • AMD CPU：需安装 AMDRyzenMaster 驱动（程序启动时自动部署）
  3. 程序以管理员权限运行（读取 CPU 温度需要系统权限）

2. 连接蓝牙桌板

  1. 确保桌板已通电，蓝牙模块（DX-BT24-T）处于可发现状态
  2. 打开 Windows 设置 → 蓝牙和其他设备 → 先与”BT24-T”配对（首次使用必须）
  3. 启动 TCV3，程序会自动扫描并连接桌板；首次连接成功后会自动记住设备地址，下次开机自动连接
  4. 连接成功后首页显示”连接完成”，风扇开始受控

如果一直提示”搜索超时”，检查：桌板是否开机、是否已在 Windows 蓝牙中配对、设备是否在 10 米范围内。

3. 界面使用

区域 说明
首页 - 温度卡片 实时 CPU / GPU 温度，超过警告阈值（默认 CPU 80℃ / GPU 75℃）图标与进度条变红
首页 - 蓝牙面板 连接状态、重连按钮
首页 - 风扇模式 自动（温度驱动调速）/ 静音（低转速）/ 全速 一键切换
首页 - 延时 数据发送间隔（1-10 秒），点”应用”生效
设置 - 外观 主题模式（跟随系统 / 浅色 / 深色）、背景材质（云母 / 亚克力 / 无）
设置 - 开机自启 开机自动运行（写入注册表）
设置 - 重置设置 删除配置文件并重启

4. 主题与背景材质

  • 浅色 / 深色主题：跟随 Windows 系统自动切换，也可手动指定
  • 云母 (Mica) / 亚克力 (Acrylic)：Windows 11 22H2 及以上系统生效；旧系统自动降级为半透明纯色

常见问题（FAQ）

蓝牙搜索不到桌板 / 连接失败

程序内的错误提示会附带排查建议，常见原因对照：

提示 解决方法
设备未找到 确认桌板已开机且在范围内；Windows 蓝牙设置中先配对”BT24-T”
访问被拒绝 在 Windows 蓝牙设置中先配对设备后再连接
设备不可达 设备可能已连接至其他主机，或超出范围，关闭其他设备的连接后重试
服务未找到 检查配置中 ServiceUUID（默认 0xFFE0）
特征值未找到 检查配置中 CharacteristicUUID（默认 0xFFE1）
写入失败 确认特征值支持写入操作
GATT 通信异常 尝试重新连接，或重启桌板电源

温度不显示或显示错误

  • Intel CPU：确认 PawnIO 驱动已安装（程序启动时检测，未安装会提示）；日志提示”IntelTemp初始化失败”时检查驱动与 MSR 权限
  • AMD CPU：确认 AMDRyzenMaster 驱动安装成功；amd_init 失败可能原因：系统版本过低（需 Win10+）、非 AMD CPU、驱动文件缺失、CPU 型号不支持
  • NVIDIA GPU：nv_dll 自动加载，无需额外驱动
  • 温度显示 “–”：当前读取失败（传感器暂时不可用），会自动恢复

风扇不转 / 不调速

  1. 确认蓝牙已连接（首页显示”连接完成”）
  2. 确认处于自动模式（静音模式下转速固定为低档）
  3. 确认数据发送延时已应用（设置后点”应用”按钮）

开机自启不生效

  • 开机自启通过注册表实现（HKCU 下的 Run 键），部分安全软件会拦截，请允许放行
  • 移动安装目录后需要重新开启一次自启动

界面主题与系统不一致

  • 检查”设置 → 外观 → 主题模式”是否选择了”跟随系统”
  • 切换系统深浅色后程序会在数秒内自动跟随

云母 / 亚克力材质不显示

  • 需要 Windows 11 22H2 及以上系统
  • 部分远程桌面 / 虚拟机环境不支持 DWM 材质，会自动降级为半透明纯色

卸载

  • 使用安装程序卸载，会清理注册表自启动项；config.ini 默认保留（可在卸载后手动删除）
